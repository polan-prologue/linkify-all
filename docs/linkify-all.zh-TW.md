# Linkify All

 [简体中文](../README.md) | 繁體中文 | [English](linkify-all.en.md)

把任意網頁中的明文網址自動變成可點擊的連結。零依賴、純本機、即時生效的油猴（Tampermonkey）使用者腳本。

> **範例效果**：頁面裡的 `https://example.com`、`www.example.com/path`、子網域 `news.example.com`
> 會被自動補全成可點擊連結（新分頁開啟）；而裸網域 `example.com`（兩段、無 www、無路徑）
> 預設**不**轉換——這是刻意的防誤判設計，詳見下文「轉換規則速查」。

---

## 功能特性

- **全站自動轉換**：頁面載入後自動掃描，把明文網址變成可點擊連結
  - 帶協定頭的完整網址（`https://…`）
  - 無協定但含 `www` 的位址（`www.example.com` → `https://www.example.com`）
  - 無協定含路徑的位址（`example.com/page/1` → `https://example.com/page/1`）
  - **子網域**位址（`news.example.com`、`sub2.example.org`，即 3 段及以上主機名，無 www 無路徑也轉換）
- **穩健防誤判**：
  - 兩段裸網域（如 `example.com`）預設不轉換，避免誤傷
  - 常見副檔名結尾的字串（`.zip/.dmg/.exe/.pdf/.torrent…`，如 GitHub Release 附件名 `example-app-1.0.17-win64.zip`）識別為**檔案名**，不轉換
  - 輸入框 / 富文字編輯器 / 程式碼區塊 / 已有連結內部 按需控制（四項場景開關，預設程式碼區塊開、其餘關）
- **動態內容感知**：MutationObserver 多根監聽（含各 Shadow DOM 根）+ 相容包裝 `attachShadow` +
  每 2.5 秒全頁保底掃描（背景分頁自動暫停），SPA 動態插入的內容也能被轉換；
  掃描按頁面變更門控並自適應降頻（靜止頁面 2.5s→30s），本體在瀏覽器空閒時段執行，
  穩態開銷趨近於零
- **低開銷設計（v1.0.6）**：觀察器批次內祖先去重（批量插入只爬最外層根）、
  自身轉換產物不再回流觀察器佇列、提取碼搜尋只對網盤連結執行、純中文/純文字節點走
  快速預篩門、場景開關與總開關記憶體快照（掃描時零 GM 儲存 IPC）、掃描實行主執行緒
  預算制（初始 ≤20ms / 保底 ≤6ms 一輪，剩餘節點分批續掃）——連結密集頁與超大頁面
  均不會出現長時間佔用主執行緒的卡頓
- **抗反識別干擾**：自動剝離網址文字中的零寬字元（U+200B 等，部分內容平台用它打斷
  自動連結識別）；連結文字被平台拆進多個相鄰節點時自動**跨節點續接**還原完整連結
  （併吞平台插入的局部錨點），避免產生殘缺短連結——續接觸發器覆蓋連結被切分的
  全部結構性位置：協定尾、主機中段、主機點號、路徑斜線；純文字行文一律保守不吞；
  Alt+點擊複製到的原文也因此更乾淨
- **場景開關**（設定面板內，即時生效）：
  1. 程式碼區塊（預設開）
  2. 富文字編輯器（預設關）
  3. 控制項文字（預設關）
  4. 已有連結內部（預設關）
- **學習規則**：遇到重複出現的固定格式文字（如 `app:abc-123` 這類「前綴:變數」），教一次即可讓同類文字全部可點擊
  - 自動推導萬用規則（固定前綴 + 變數 + 固定後綴），儲存前自動校驗「樣本→連結」往返一致
  - 變數按數字 / 字母 / 混合三類自動泛化，詞邊界保護防部分詞誤配；變數不含 CJK 防吞字
  - 同形規則自動去重（重複教學 = 重新啟用並更新樣本）；最多儲存 200 條
  - 清單內可單獨停用 / 刪除，停用或刪除會即時還原本頁已轉換的連結
- **網盤提取碼自動填入**：識別網盤分享連結附近的提取碼併入連結
  - 按「提取碼 / 存取碼 / 密碼 / 密鑰 / pwd」等關鍵字，在連結右側 80 / 左側 60 字元內比對 4–10 位英數提取碼
  - 百度網盤走官方 `?pwd=` 參數；其他網盤把提取碼寫入連結雜湊，開啟分享頁後自動定位輸入框填入並嘗試送出
  - 目前內建識別：百度網盤、夸克網盤、藍奏雲、阿里雲盤、天翼雲盤、115、迅雷雲盤、123 雲盤、移動雲盤、騰訊微雲、UC 網盤等主流網盤
- **失效連結偵測**：背景匿名探測轉換出的連結，失效時加刪除線並提示「可能失效」
  - HEAD 優先（伺服器拒絕 405 時自動降級 GET）；404/410 及連線失敗、逾時判為失效，2xx–4xx 視為正常
  - 匿名請求不帶 Cookie；限流每頁 20 條、並發 2、單請求 9 秒逾時；結果快取 24 小時（本機至多 500 條）
- **設定備份與還原**：
  - 本機備份：JSON 匯出 / 匯入（檔案選擇 + 面板貼上雙通道），按規則內容合併去重
  - **WebDAV 版本化雲端備份**：每次備份按時間戳獨立存檔、互不覆蓋；還原時列出雲端全部歷史版本，自由選擇任一版本回滾；目錄缺失自動建立（適配堅果雲等根目錄禁寫入的服務）
- **站點黑名單**：一鍵把目前站點加入 / 移出黑名單，黑名單站點不執行任何轉換
  （v1.0.8 起子網域繼承：加入 `example.com` 即覆蓋 `www.example.com`）
- **即時生效**：總開關、黑名單、規則增刪改、場景開關，全部無需重新整理頁面
- **跨分頁同步**：任意分頁變更設定，其它已開啟的分頁即時跟隨（v1.0.8）
- **零依賴零遙測**：無第三方函式庫、無統計上報、不收集不上傳任何瀏覽資料

## 安裝

需要先安裝 **Tampermonkey** 瀏覽器擴充功能（Chrome / Edge 等 Chromium 核心瀏覽器均可，見「已知邊界」），然後：

### 方式一：一鍵安裝（推薦）

按網路環境任選其一，兩個位址的腳本內容完全一致：

- **國內網路（推薦，CNB 直連更快）**
  **👉 [點此安裝 Linkify All](https://cnb.cool/xkelin/LinkifyAll/-/git/raw/main/linkify-all.user.js)**
- **國際網路 / GitHub**
  **👉 [點此安裝 Linkify All](https://raw.githubusercontent.com/polan-prologue/linkify-all/main/linkify-all.user.js)**

點擊後 Tampermonkey 會自動彈出安裝確認頁，點「安裝」即可。以後升級也是點同一個連結。

### 方式二：手動安裝

1. 開啟 Tampermonkey 管理面板 → 「新增腳本」
2. 刪除編輯器裡的範本內容，貼上 [`linkify-all.user.js`](../linkify-all.user.js) 全部程式碼
3. `Ctrl+S` 儲存，腳本即刻生效

### 升級方式

- 已安裝使用者：重新點一次「一鍵安裝」連結，Tampermonkey 會識別為更新並保留你的全部本機資料（規則 / 黑名單 / 設定）
- v1.0.0 起為首次公開版本，前身為內部迭代版本（見 [CHANGELOG.md](../CHANGELOG.md)）

## 快速上手

安裝後開啟任意網頁，明文網址會自動變成可點擊連結。常用操作：

| 操作 | 方式 |
|---|---|
| 全域開關 | 點擊瀏覽器工具列 Tampermonkey 圖示 → 「總開關」 |
| 目前站點加入黑名單 | Tampermonkey 選單 → 「把目前站點加入黑名單」（再點一次移出；v1.0.8 起含子網域） |
| 教一條新規則 | Tampermonkey 選單 → 「🎓 學習新規則…」 |
| 開啟設定面板 | Tampermonkey 選單 → 「⚙️ 設定」 |
| 複製原文（含提取碼） | **Alt + 點擊**轉換出的連結；連結帶提取碼時會連同提取碼一起複製 |
| 直連跳轉 | **Ctrl + 點擊**（macOS 為 **Cmd + 點擊**）頁面中的明文網址文字；即使被防誤判邏輯跳過（如兩段裸網域 `example.com`、檔案名 `app.zip`），也能一鍵直達 |

## 設定面板詳解

油猴選單共 4 項：**總開關 / 黑名單 / 🎓 學習新規則… / ⚙️ 設定**。設定面板（可拖動、Esc 關閉、內容超高時內部捲動）整合了四大模組：

### 1. 場景開關

決定腳本在哪些區域執行轉換，全部即時生效、無需重新整理：

| 場景 | 預設 | 說明 |
|---|---|---|
| 程式碼區塊 | 開 | `<pre>`、`<code>` 內的文字（放行便於複製，也可關閉） |
| 富文字編輯器 | 關 | 可編輯富文字區域（避免打斷輸入） |
| 控制項文字 | 關 | 按鈕 / 標籤控制項裡的文字 |
| 已有連結內部 | 關 | 已存在的 `<a>` 標籤內部文字（預設不動，避免破壞原連結） |

每個開關懸浮可見說明；切換後整頁「先還原再轉換」，無需重新整理。

### 2. 學習規則管理

- **新建規則**：規則清單頂部即「＋ 學習新規則」入口（sticky 固定，捲動清單時始終可見）
  - 輸入一對「原文字 → 跳轉連結」，例如 `論壇:t/123456 → https://example.com/p/123456`
  - 填寫時即時預覽推導結果（形如「前綴⟨數字⟩ → 連結⟨數字⟩」），不成立會提示原因
  - 學習視窗不擋頁面：先在頁面選取文字再點「📌 擷取選取文字」即可填入；原文字框按 Enter 跳到連結框，連結框按 Enter 直接儲存
- **規則清單**：每條規則顯示樣本對照（`原文字 → 跳轉連結`），可單獨停用 / 刪除（即時還原相關連結）；清單內部捲動，大數量不卡
- 規則存於本機，隨備份匯出 / 還原

### 3. WebDAV 雲端備份

填寫你自己的 WebDAV 服務位址與憑證後可用（位址欄預設提示 `https://dav.jianguoyun.com/dav/`，堅果雲需使用「應用程式密碼」而非登入密碼）：

- 每次「備份」按時間戳產生獨立檔案（`backup-年月日-時分秒.json`，存於伺服器 `/linkify/` 子目錄），歷史版本互不覆蓋
- 目標目錄不存在時自動建立（MKCOL）並重試一次
- 「還原」時列出雲端全部歷史版本（新→舊），自由選擇任一版本匯入；目前規則不會被刪除，同名規則自動去重
- 密碼支援中文等非 Latin1 字元（UTF-8 Basic Auth）；憑證僅存於本機 Tampermonkey 儲存，不隨備份檔案匯出或外發

### 4. 本機備份 / 遷移

- **匯出到本機檔案**：下載 `linkify-all-backup-年月日.json`；瀏覽器攔截下載時自動降級為 data URI 方式，再不行彈出手動複製面板
- **匯入**：選擇本機檔案匯入，或把 JSON 直接貼到文字框點「從貼上匯入」
- 匯出內容 = 學習規則 + 黑名單 + 總開關 + 場景開關；匯入為**合併式**（同名規則自動去重，不刪除現有資料），非法檔案會被拒絕並提示

## 轉換規則速查

| 輸入 | 是否轉換 | 結果 |
|---|---|---|
| `https://example.com/path/123` | ✅ | 原樣轉連結 |
| `www.example.com/path` | ✅ | 補全 `https://` 後轉連結 |
| `example.com/page/1` | ✅ | 補全 `https://` 後轉連結 |
| `news.example.com`（3 段子網域） | ✅ | 補全 `https://` 後轉連結 |
| `example.com`（兩段裸網域） | ❌ 預設 | 防誤判，刻意不轉 |
| `example-app-1.0.17-win64.zip` | ❌ | 識別為檔案名（副檔名黑名單，無 `/`） |
| `github.com/example-org/app/releases/download/1.0/app.apk` | ✅ | 含路徑的下載直連不做檔案名否決（v1.0.8） |
| `https://github.com/.../example-app-1.0.17-win64.zip` | ✅ | 帶協定頭的完整直連不誤傷 |
| `Chrome.120.Release` | ❌ | 末段不是公共後綴，不當網域（v1.0.8 起） |
| 輸入框 / 富文字編輯器 / 程式碼區塊 / 已有連結內部 | 視場景開關 | 預設程式碼區塊開，其餘預設關 |

> **v1.0.8 判定原則**：訊號越弱，要求越嚴。帶協定頭 / `www` 前綴 / 含路徑 = 強訊號，
> 直接轉換；只有「無協定、無 `www`、無路徑的三段主機」這種最弱形態，才要求末段命中
> 公共後綴白名單（ccTLD + 主流 gTLD + RFC 2606 保留域）。

## 權限與隱私

- **零依賴、零遙測**：無任何統計上報；不收集、不上傳任何瀏覽資料
- **`@connect *`**：僅服務於兩個**使用者主動發起**的功能——
  1. 失效偵測：對剛轉換出的連結發匿名 HEAD/GET（不帶 Cookie）；v1.0.8 起內網位址
     （`localhost` / `192.168.*` / `10.*` / `*.local` / IPv6 環回與 ULA 等）一律跳過
  2. WebDAV 雲端備份：連線你**自己填寫**的伺服器位址
  除此之外腳本不發起任何網路請求
- **`GM_addValueChangeListener`**（v1.0.8）：僅用於監聽本機 Tampermonkey 儲存的鍵值
  變化以實現跨分頁設定同步，資料不出本機，不發起任何網路請求
- **WebDAV 憑證**僅儲存在本機 Tampermonkey 儲存中，匯出備份檔案不含憑證
- 腳本以相容方式包裝 `Element.prototype.attachShadow` 以感知動態元件（不改其行為，相容開放 Shadow DOM）
- 所有資料存於本機 Tampermonkey 儲存：總開關 / 黑名單 / 場景開關 / 學習規則 / 失效偵測結果快取 / WebDAV 憑證，**解除安裝腳本即全部清除**

## 已知邊界

- 兩段裸網域（`example.com`）預設不轉換——防誤判設計；子網域（3 段及以上）會轉換
- 無協定、無 `www`、無路徑的三段主機要求末段命中內建公共後綴白名單；極冷門 TLD
  的裸網域不會被自動轉換（補上 `https://` 或 `www.` 即正常識別）
- 副檔名黑名單包含 `zip/mov/app` 等同時是開放 gTLD 的後綴（防 Release 附件名
  誤判優先於網域判斷）；**含 `/` 的候選不做此否決**，下載直連不受影響
- 不進入 iframe；封閉 Shadow DOM 無法存取（僅穿透開放 Shadow DOM）
- 支援 Chromium 核心瀏覽器（Chrome / Edge / 新版 Opera 等）；**Firefox 未適配**
- 學習規則變數不含 CJK 字元（防吞字）；中文標點後的漢字不會被吞入連結
- 非 HTML 命名空間（如 SVG 內部）的文字不轉換；單一文字節點超過 5 萬字元跳過（效能護欄）

## 開發與測試

`tests/regression.test.js` 是**零依賴**的 Node 回歸測試（內建最小 DOM mock，含
Shadow DOM / MutationObserver / TreeWalker 的保真模擬）。該檔案僅本機維護，
不隨倉庫發布。

```bash
# 方式一：倉庫根目錄
node tests/regression.test.js ./linkify-all.user.js
# 方式二：tests 目錄
cd tests && node regression.test.js ../linkify-all.user.js
```

- 參數為被測腳本路徑，可指向任意歷史版本做行為對比
- 覆蓋：Shadow DOM 穿透、跨節點續接（協定尾 / 主機中段 / 點號 / 斜線邊界）、
  週期性保底掃描、中文語境（全形標點 / 中文 / 提取碼）、學習規則泛化與批次教學、
  備份匯出匯入往返、副檔名否決、公共後綴白名單、偽協定防護、面板免疫等
- 測試資料全部使用 `example.com` 系列佔位網域（網盤連結使用測試專用的網盤網域），不依賴任何真實站點
- 目前全綠輸出：`總計 124 項，通過 124 項，失敗 0 項`

## 常見問題

**Q：為什麼我打 `example.com` 不加 `www` 不變連結？**
A：兩段裸網域在正文裡太常見（可能是檔案名、參數、正文片段），轉換誤傷率最高，故預設不轉。3 段及以上子網域會自動轉換；帶 `www` 或路徑也會轉換。

**Q：為什麼 `example-app-1.0.17-win64.zip` 沒變連結？**
A：`.zip` 等在副檔名黑名單裡，且整串不含 `/`（即裸附件名形態），會被識別為檔案名。
v1.0.8 起，含路徑的下載直連（如 `github.com/xxx/releases/download/1.0/app.apk`）
不再受此規則影響，會正常轉換。

**Q：換電腦 / 重新安裝瀏覽器怎麼遷移設定？**
A：設定面板 → 匯出 JSON 儲存；新環境安裝腳本後 → 匯入即可。需要跨裝置自動遷移可用 WebDAV 雲端備份，還原時可選擇任一歷史版本。

**Q：失效偵測會不會被網站封鎖？**
A：偵測為匿名請求、不帶 Cookie、限流（每頁 20 條 / 並發 2 / 結果快取 24h），對站點壓力極小。個別站點仍可能拒絕，屬正常現象。

**Q：如何徹底解除安裝？**
A：Tampermonkey 管理面板 → 刪除本腳本即可，全部本機資料隨解除安裝清除。

**Q：支援 Firefox 嗎？**
A：暫未適配（腳本使用 ES2020 特性，Firefox 需另行適配）。
