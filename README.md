# Linkify All

把任意网页中的明文网址自动变成可点击的链接。零依赖、纯本地、即时生效的油猴（Tampermonkey）用户脚本。

> **示例效果**：页面里的 `https://example.com`、`www.example.com/path`、子域名 `news.example.com`
> 会被自动补全成可点击链接（新标签页打开）；而裸域名 `example.com`（二段、无 www、无路径）
> 默认**不**转换——这是刻意的防误判设计，详见下文「转换规则速查」。

---

## 功能特性

- **全站自动转换**：页面加载后自动扫描，把明文网址变成可点击链接
  - 带协议头的完整网址（`https://…`）
  - 无协议但含 `www` 的地址（`www.example.com` → `https://www.example.com`）
  - 无协议含路径的地址（`example.com/page/1` → `https://example.com/page/1`）
  - **子域名**地址（`news.example.com`、`sub2.example.org`，即 3 段及以上主机名，无 www 无路径也转换）
- **稳健防误判**：
  - 二段裸域名（如 `example.com`）默认不转换，避免误伤
  - 常见文件扩展名结尾的字符串（`.zip/.dmg/.exe/.pdf/.torrent…`，如 GitHub Release 附件名 `example-app-1.0.17-win64.zip`）识别为**文件名**，不转换
  - 输入框 / 富文本编辑器 / 代码块 / 已有链接内部 默认不碰（均可通过场景开关调整）
- **动态内容感知**：MutationObserver 多根监听（含各 Shadow DOM 根）+ 兼容包装 `attachShadow` +
  每 2.5 秒全页兜底扫描（后台标签页自动暂停），SPA 动态插入的内容也能被转换；
  扫描按页面变更门控并自适应降频（静止页面 2.5s→30s），本体在浏览器空闲时段执行，
  稳态开销趋近于零
- **低开销设计（v1.0.6）**：观察器批内祖先去重（批量插入大树只爬最外层根）、
  自身转换产物不再回流观察器队列、提取码搜索只对网盘链接执行、纯中文/纯文本节点走
  快速预筛门、场景开关与总开关内存快照（扫描时零 GM 存储 IPC）、扫描实行主线程
  预算制（初始 ≤20ms / 兜底 ≤6ms 一轮，剩余节点分批续扫）——链接密集页与超大页面
  均不会出现长时间占用主线程的卡顿
- **抗反识别干扰**：自动剥离网址文本中的零宽字符（U+200B 等，部分内容平台用它打断
  自动链接识别）；链接文本被平台拆进多个相邻节点时自动**跨节点续接**还原完整链接
  （并吞并平台插入的局部锚点），避免产生残缺短链——续接触发器覆盖链接被切分的
  全部结构性位置：协议尾、主机中段、主机点号、路径斜杠；纯文本行文一律保守不吞；
  Alt+点击复制到的原文也因此更干净
- **场景开关**（设置面板内，即时生效）：
  1. 代码块（默认开）
  2. 富文本编辑器（默认关）
  3. 控件文本（默认关）
  4. 已有链接内部（默认关）
- **学习规则**：遇到重复出现的固定格式文本（如 `app:abc-123` 这类"前缀:变量"），教一次即可让同类文本全部可点击
  - 自动推导通配规则（固定前缀 + 变量 + 固定后缀），保存前自动校验「样本→链接」往返一致
  - 变量按数字 / 字母 / 混合三类自动泛化，词边界保护防部分词误匹配；变量不含 CJK 防吞字
  - 同形规则自动去重（重复教学 = 重新启用并更新样本）；最多保存 200 条
  - 列表内可单独停用 / 删除，停用或删除会即时还原本页已转换的链接
- **网盘提取码自动填入**：识别网盘分享链接附近的提取码并并入链接
  - 按「提取码 / 访问码 / 密码 / 密钥 / pwd」等关键词，在链接右侧 80 / 左侧 60 字符内匹配 4–10 位字母数字提取码
  - 百度网盘走官方 `?pwd=` 参数；其他网盘把提取码写入链接哈希，打开分享页后自动定位输入框填入并尝试提交
  - 目前内置识别：百度网盘、夸克网盘、蓝奏云、阿里云盘、天翼云盘、115、迅雷云盘、123 云盘、移动云盘、腾讯微云、UC 网盘等主流网盘
- **失效链接检测**：后台匿名探测转换出的链接，失效时中划线并提示「可能失效」
  - HEAD 优先（服务器拒绝 405 时自动降级 GET）；404/410 及连接失败、超时判为失效，2xx–4xx 视为正常
  - 匿名请求不带 Cookie；限流每页 20 条、并发 2、单请求 9 秒超时；结果缓存 24 小时（本机至多 500 条）
- **配置备份与恢复**：
  - 本地备份：JSON 导出 / 导入（文件选择 + 面板粘贴双通道），按规则内容合并去重
  - **WebDAV 版本化云备份**：每次备份按时间戳独立存档、互不覆盖；恢复时列出云端全部历史版本，自由选择任一版本回滚；目录缺失自动创建（适配坚果云等根目录禁写入的服务）
- **站点黑名单**：一键把当前站点加入 / 移出黑名单，黑名单站点不执行任何转换
- **即时生效**：总开关、黑名单、规则增删改、场景开关，全部无需刷新页面
- **零依赖零遥测**：无第三方库、无统计上报、不收集不上传任何浏览数据

## 安装

需要先安装 **Tampermonkey** 浏览器扩展（Chrome / Edge 等 Chromium 内核浏览器均可，见「已知边界」），然后：

### 方式一：一键安装（推荐）

按网络环境任选其一，两个地址的脚本内容完全一致：

- **国内网络（推荐，CNB 直连更快）**
  **👉 [点此安装 Linkify All](https://cnb.cool/xkelin/LinkifyAll/-/git/raw/main/linkify-all.user.js)**
- **国际网络 / GitHub**
  **👉 [点此安装 Linkify All](https://raw.githubusercontent.com/polan-prologue/linkify-all/main/linkify-all.user.js)**

点击后 Tampermonkey 会自动弹出安装确认页，点「安装」即可。以后升级也是点同一个链接。

### 方式二：手动安装

1. 打开 Tampermonkey 管理面板 → 「新建脚本」
2. 删除编辑器里的模板内容，粘贴 [`linkify-all.user.js`](./linkify-all.user.js) 全部代码
3. `Ctrl+S` 保存，脚本即刻生效

### 升级方式

- 已安装用户：重新点一次「一键安装」链接，Tampermonkey 会识别为更新并保留你的全部本地数据（规则 / 黑名单 / 设置）
- v1.0.0 起为首次公开版本，前身为内部迭代版本（见 [CHANGELOG.md](./CHANGELOG.md)）

## 快速上手

安装后打开任意网页，明文网址会自动变成可点击链接。常用操作：

| 操作 | 方式 |
|---|---|
| 全局开关 | 点击浏览器工具栏 Tampermonkey 图标 → 「总开关」 |
| 当前站点加入黑名单 | Tampermonkey 菜单 → 「把当前站点加入黑名单」（再点一次移出） |
| 教一条新规则 | Tampermonkey 菜单 → 「🎓 学习新规则…」 |
| 打开设置面板 | Tampermonkey 菜单 → 「⚙️ 设置」 |
| 复制原文（含提取码） | **Alt + 点击**转换出的链接；链接带提取码时会连同提取码一起复制 |
| 直链跳转 | **Ctrl + 点击**页面中的明文网址文本；即使被防误判逻辑跳过（如二段裸域名 `example.com`、文件名 `app.zip`），也能一键直达 |

## 设置面板详解

油猴菜单共 4 项：**总开关 / 黑名单 / 🎓 学习新规则… / ⚙️ 设置**。设置面板（可拖动、Esc 关闭、内容超高时内部滚动）整合了四大模块：

### 1. 场景开关

决定脚本在哪些区域执行转换，全部即时生效、无需刷新：

| 场景 | 默认 | 说明 |
|---|---|---|
| 代码块 | 开 | `<pre>`、`<code>` 内的文字（放行便于复制，也可关闭） |
| 富文本编辑器 | 关 | 可编辑富文本区域（避免打断输入） |
| 控件文本 | 关 | 按钮 / 标签控件里的文字 |
| 已有链接内部 | 关 | 已存在的 `<a>` 标签内部文字（默认不动，避免破坏原链接） |

每个开关悬浮可见说明；切换后整页「先还原再转换」，无需刷新。

### 2. 学习规则管理

- **新建规则**：规则列表顶部即「＋ 学习新规则」入口（sticky 固定，滚动列表时始终可见）
  - 输入一对「原文本 → 跳转链接」，例如 `论坛:t/123456 → https://example.com/p/123456`
  - 填写时实时预览推导结果（形如「前缀⟨数字⟩ → 链接⟨数字⟩」），不成立会提示原因
  - 学习窗口不挡页面：先在页面选中文字再点「📌 抓取选中文字」即可填入；原文本框回车跳到链接框，链接框回车直接保存
- **规则列表**：每条规则显示样本对照（`原文本 → 跳转链接`），可单独停用 / 删除（即时还原相关链接）；列表内部滚动，大数量不卡
- 规则存于本机，随备份导出 / 恢复

### 3. WebDAV 云备份

填写你自己的 WebDAV 服务地址与凭据后可用（地址栏默认提示 `https://dav.jianguoyun.com/dav/`，坚果云需使用「应用密码」而非登录密码）：

- 每次「备份」按时间戳生成独立文件（`backup-年月日-时分秒.json`，存于服务器 `/linkify/` 子目录），历史版本互不覆盖
- 目标目录不存在时自动创建（MKCOL）并重试一次
- 「恢复」时列出云端全部历史版本（新→旧），自由选择任一版本导入；当前规则不会被删除，同名规则自动去重
- 密码支持中文等非 Latin1 字符（UTF-8 Basic Auth）；凭据仅存于本机 Tampermonkey 存储，不随备份文件导出或外发

### 4. 本地备份 / 迁移

- **导出到本地文件**：下载 `linkify-all-backup-年月日.json`；浏览器拦截下载时自动降级为 data URI 方式，再不行弹出手动复制面板
- **导入**：选择本地文件导入，或把 JSON 直接粘贴到文本框点「从粘贴导入」
- 导出内容 = 学习规则 + 黑名单 + 总开关 + 场景开关；导入为**合并式**（同名规则自动去重，不删除现有数据），非法文件会被拒绝并提示

|---|---|---|

## 权限与隐私

- **零依赖、零遥测**：无任何统计上报；不收集、不上传任何浏览数据
- **`@connect *`**：仅服务于两个**用户主动发起**的功能——
  1. 失效检测：对刚转换出的链接发匿名 HEAD/GET（不带 Cookie）
  2. WebDAV 云备份：连接你**自己填写**的服务器地址
  除此之外脚本不发起任何网络请求
- **WebDAV 凭据**仅保存在本机 Tampermonkey 存储中，导出备份文件不含凭据
- 脚本以兼容方式包装 `Element.prototype.attachShadow` 以感知动态组件（不改其行为，兼容开放 Shadow DOM）
- 所有数据存于本机 Tampermonkey 存储：总开关 / 黑名单 / 场景开关 / 学习规则 / 失效检测结果缓存 / WebDAV 凭据，**卸载脚本即全部清除**

## 已知边界

- 二段裸域名（`example.com`）默认不转换——防误判设计；子域名（3 段及以上）会转换
- 文件扩展名黑名单包含 `zip/mov/app` 等同时是开放 gTLD 的后缀（防 Release 附件名误判优先于域名判断）
- 不进入 iframe；封闭 Shadow DOM 无法访问（仅穿透开放 Shadow DOM）
- 支持 Chromium 内核浏览器（Chrome / Edge / 新版 Opera 等）；**Firefox 未适配**
- 学习规则变量不含 CJK 字符（防吞字）；中文标点后的汉字不会被吞入链接
- 非 HTML 命名空间（如 SVG 内部）的文本不转换；单个文本节点超过 5 万字符跳过（性能护栏）

## 常见问题

**Q：为什么我打 `example.com` 不加 `www` 不变链接？**
A：二段裸域名在正文里太常见（可能是文件名、参数、正文片段），转换误伤率最高，故默认不转。3 段及以上子域名会自动转换；带 `www` 或路径也会转换。

**Q：为什么 `example-app-1.0.17-win64.zip` 没变链接？**
A：`.zip` 等在扩展名黑名单里，整串被识别为文件名。软件下载链接建议直接复制带 `https://` 的完整直链，会正常转换。

**Q：换电脑 / 重装浏览器怎么迁移配置？**
A：设置面板 → 导出 JSON 保存；新环境安装脚本后 → 导入即可。需要跨设备自动迁移可用 WebDAV 云备份，恢复时可选择任一历史版本。

**Q：失效检测会不会被网站屏蔽？**
A：检测为匿名请求、不带 Cookie、限流（每页 20 条 / 并发 2 / 结果缓存 24h），对站点压力极小。个别站点仍可能拒绝，属正常现象。

**Q：如何彻底卸载？**
A：Tampermonkey 管理面板 → 删除本脚本即可，全部本地数据随卸载清除。

**Q：支持 Firefox 吗？**
A：暂未适配（脚本使用 ES2020 特性，Firefox 需另行适配）。
